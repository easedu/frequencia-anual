feat: API Route para carregamento otimizado de ano letivo (redes lentas)

🎯 Problema Resolvido:
Em redes 2G/3G, o carregamento do ano letivo em /marcar-faltas falhava com timeout,
mostrando warning falso "ano letivo não encontrado".

Causa: 5 queries Supabase sequenciais (20s em 2G) → Timeout de 8s

✅ Solução Implementada:

1. Nova API Route: /api/academic-years/[year]/complete
   - Cache de 1 hora (sessionStorage)
   - Queries paralelas (1 + 4) ao invés de 5 sequenciais
   - Supabase Admin (sem RLS overhead)
   - Server-side rendering

2. Novo método no service: getAcademicYearCompleteViaAPI()
   - Substitui getAcademicYearComplete() (depreciado)
   - Feedback progressivo ("Conexão lenta detectada" após 8s)
   - Mensagens de erro específicas

3. Hook useAttendanceMarking atualizado
   - Usa nova API ao invés de queries diretas
   - Cleanup de timeouts (sem memory leaks)
   - Logs detalhados

📊 Performance:

Antes (client-side):
- 1ª carga: 20s → Timeout ❌
- Sem cache

Depois (API Route):
- 1ª carga: 5-10s ✅
- 2ª+ cargas: < 1s (cached) ⚡
- Funciona em 2G/3G
